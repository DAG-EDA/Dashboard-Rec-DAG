Please act as a creative brainstorming colleague for a dashboard designer. You will primarily support the dashboard designer by decomposing a question into conceptual paths to support answering the question.


Instructions:
Given a question: Is there discrimination in mortgage lending? Which demographics are the most affected?
Develop concepts that are necessary for developing domain knowledge on this question
For [threshold] iterations, recursively decompose the concepts from the previous iteration to further define and characterize them -> each iteration should produce multiple nodes that together serve to quantify the node from the previous iteration
In the final iteration, you should have nodes that are quantifiable and concrete
For each iteration, include a “node” and an “edge”
Build up a JSON file to represent the knowledge graph that you have built up in adjacency list format
Remember that each node, including those with higher-level concepts, should be connected to other
nodes and have multiple parents/children. This is a graph,  not a tree - make sure that we can clearly
see the correlation between more abstract concepts as well as between more specific concepts
using the same format as defined below. Additionally, include cross-cutting relationships where the
different concepts influence each other.
This graph **must be a DIRECTED ACYCLIC GRAPH**. Thus, ensure that there are no cycles in the graph (specifically,
nodes from a subsequent iteration do not connect back to nodes from a prior iteration - relationships are
only one way).


Definitions:
Node: The specific concept (e.g., “Barack Obama”, “Michelle Obama”)
Edge: A short predicate connecting this node with the equivalent node from the previous iteration (e.g., for nodes “Barack Obama” and “Michelle Obama”, the edge would be “Married To”) 
Threshold: 5 iterations
Conceptual path: For a single conceptual node the neighboring nodes and corresponding edges form a path of concepts that represent the decomposition of a concept into greater granularity.
Quantifiable: At its core, a quantifiable concept is one that can be represented as an attribute in a graph (i.e., it is specific and measurable by some metric (such as “Approval Rating”, or it is a base concept that cannot be simplified any further, such as “Barack Obama”). In each iteration, nodes should move closer to achieving this goal of being quantifiable, until in the final iteration, nodes fulfill this criterion.
Cross-Cutting Relationships: Relationships between nodes from different iteration pathways. This does **not** include
relationships between nodes in the same iteration pathway.
